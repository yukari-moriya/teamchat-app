# 画面（Blade・CSS）の書き方

正本は `docs/design/screens.md` と `mockup/`。`mockup/` は**見た目の正本で、書き込み禁止**。読むだけ。

ピクセル一致は要らない。合わせるのは**並び・項目・言葉づかい・状態の見せ方**。PCのみ（最小幅1280px、スマートフォンの表示は考えない）。

画面の状態の持ち方と戻り先は、`screens.md` の0章と `permissions-api.md` の2-2・2-3 を先に読む。

## 文言を自分で考えない

画面に出す文言・エラー文・placeholder は、`screens.md` の3章・4章と `mockup/` の該当HTMLから**一字一句そのまま**写す。言い換えると、設計書と違うものが画面に出る。どちらにも無ければ聞く。

- エラー文は**1文・句点なし**（例:「チャンネル名を入力してください」）
- 日時は `2026/08/17 14:32` の形（日本時間）
- アプリ名は「チームチャットアプリ」
- 全角スペースや中黒（`　·　`）も、モックアップにあるとおりに写す

モックアップの `※` で始まる灰色の注記（`mock-note`）は**見本のための注記**で、アプリの画面には出さない。

## 値をそのまま出さない

- 入力欄に戻す前回の値は `\App\Support\OldInput::text()` を通し、`old()` のまま出さない（値を比べるだけならよい）。画面を通さずに配列を送られると `old()` が配列を返し、**画面が 500 になる**。前回の値は欄ごとではなくまとめて持ち越すので、どの欄も通す。
- URL のクエリの値も配列で届く（`?q[]=x`）。文字列だと確かめてから出す。
- `{!! !!}` を使わない。

## CSS は `public/css/app.css` が正本

**Vite は使っていない。**`resources/css/app.css` は空で、`@vite()` はどこにも無い。Blade は `asset('css/app.css')` で `public/` を直接読んでいる。`resources/` 側を編集しても画面は変わらない。

`public/css/app.css` は、前半が `mockup/styles.css` の写し。**アプリ側で足した規則は、ファイル末尾の「アプリで足した分」の節にだけ**、なぜ足したかのコメントを付けて置く。写した部分に手を入れない。

## 新しく足すスタイルは、直値で書かない

色・余白・角丸には CSS 変数がある（`--sp-4`・`--r-md`・`--danger` など。`mockup/design-guide.md`）。モックアップに無いクラスを作る前に、`public/css/app.css` に定義済みのものを探す。**見本にある直値は、そのまま写してよい**（写した部分や、画面の `style` 属性にも直値がある）。直値を見つけても、置き換えない。

## 画面の項目を勝手に増やさない・減らさない

項目の正本は `screens.md` の3章（項目を書いていない画面は `mockup/`）。足りないと思っても足さない。条件付きで出す項目（作成者にだけ出すボタンなど）は、**サーバ側でも同じ条件を確かめる**。UIで隠すことは判定の代わりにならない。

操作の出し分けは `@can` でポリシーに聞く。`is_private` を直接見るのは、記号・バッジ・文言の出し分けだけ。

## 繰り返す部品を書き直さない

`resources/views/components/` に、`<x-message>`（メッセージと返信の行）・`<x-avatar>`（頭文字2字のアバター）・`<x-channel-sign>`（チャンネルの記号）・`<x-channel-badge>`（公開範囲のバッジ）がある。同じものを別の場所で書き直さない。画面の中だけで分ける部品は、`channels/_thread.blade.php` のように `_` で始める。

- **削除済みの表示は `<x-message>` にだけ書く。**ほかの場所で分岐すると、消した本文が出る出口が増える（D-05 の補足）。
- `msg__body` の中に、余分な空白を入れない。空白もそのまま表示される。
- `$message` という変数を使っている範囲では、`@error` と `@else` を組にしない。`@else` の側を通ると、`$message` が消える。

## アバターの色は利用者のIDから決める

その場の並び順で割り当てると、画面ごとに同じ人の色が変わる。`<x-avatar>` が `$user->id` から決めているので、これを使う。
